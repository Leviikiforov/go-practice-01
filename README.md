# Практическая работа № 2. Сводка статусов задач

Курс «Бэкенд-разработка на языке Go».

## Окружение

- Операционная система: Windows
- Версия Go: go1.27.4 windows/386
- Редактор: Visual Studio Code

## Выполнено

Создана программа сводки статусов учебных задач в `cmd/task-summary/main.go`.
Реализованы функции `statusLabel`, `countStatus`, а также словарь частот `map[string]int`.
Дополнительное задание: `findStatus` и `completionPercent`.

## Запуск программы

Команда в терминале и результат её выполнения.
```
go run ./cmd/task-summary
Задач всего: 5
1. Новая
2. В работе
3. Завершена
4. Завершена
5. Новая
Завершено: 2
Статистика: new=2, in_progress=1, done=2
```

## Проверка сборки и оформления

Команда в терминале и результат её выполнения.
```
go fmt ./...
go build ./...
go vet ./...
```

## Проверенные данные

Программа проверена на четырёх сценариях из таблицы методички, а также на неизвестных статусах.

**1. Обычный сценарий** — `{"new", "in_progress", "done", "done"}` + `append("new")`:
```
Задач всего: 5
1. Новая
2. В работе
3. Завершена
4. Завершена
5. Новая
Завершено: 2
Статистика: new=2, in_progress=1, done=2
```

**2. Пустой список** — `[]string{}` без append:
```
Задач всего: 0
Завершено: 0
Статистика: new=0, in_progress=0, done=0
```
Нумерованные строки отсутствуют, паники нет.

**3. Одна задача** — `[]string{"done"}` без append:
```
Задач всего: 1
1. Завершена
Завершено: 1
Статистика: new=0, in_progress=0, done=1
```

**4. Нет завершённых** — `[]string{"new", "new"}` без append:
```
Задач всего: 2
1. Новая
2. Новая
Завершено: 0
Статистика: new=2, in_progress=0, done=0
```

**Неизвестный статус** — проверка `statusLabel`:
```
fmt.Println(statusLabel("blocked")) // Неизвестный статус
fmt.Println(statusLabel(""))        // Неизвестный статус
```

**Дополнительное задание** — проверка `findStatus` и `completionPercent`:
- `findStatus` находит индекс первого совпадения, возвращает `-1` для отсутствующего статуса и на пустом срезе.
- `completionPercent` возвращает `0` для пустого среза (без деления на ноль).
```
go run ./cmd/task-summary
Задач всего: 0
Завершено: 0
Индекс первого совпавшего статуса: -1
Доля выполненных задач: 0.000000
Статистика: new=0, in_progress=0, done=0
```

```
go run ./cmd/task-summary
Задач всего: 5
1. Новая
2. В работе
3. Завершена
4. Завершена
5. Новая
Завершено: 2
Индекс первого совпавшего статуса: 2
Доля выполненных задач: 40.000000
Статистика: new=2, in_progress=1, done=2
```
